# Frontend workflow convention

For any workflow progress UI, use `app/workflow-stepper.tsx` and its shared stylesheet. Follow the section Maintain the application and approved design in the [single handover](../lapi_docs/Lapi_Architecture_and_Deployment_Handover.docx). Actual step names and live statuses are required. Keep the approved compact horizontal blue/white markers, checkmarks, dark-blue rotating ring and incoming particle flow consistent across all workflows. Do not create an independent stepper without an explicit user request to change the standard.

Use `app/agent-logo.tsx` for the Lapi Agent identity and the same handover section. Lapi brand (approved 27 October 2026): the mark is an L with a speech-bubble P. `public/lapi-mark.svg` (on white) is used in the header, sign-in card and banner; `public/lapi-agent.svg` (blue tile) is the Agent icon, browser icon and app icon (PNG copies `lapi-mark-180.png`, `lapi-mark-512.png`, `favicon.ico`). The wordmark is `public/lapi-wordmark.svg` (`lapi-wordmark-white.svg` on blue). Palette: blue #2563EB, deep blue #1D4ED8, light orange #FDBA74, orange #FB923C, white, ink #14213D. Keep workflow status icons separate. Preserve legacy assistant route aliases when changing navigation.
