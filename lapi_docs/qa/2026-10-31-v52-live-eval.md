## Limits

- The files are plain text and CSV, so OCR, PDF, images and handwriting were not tested.
- The empty-field second look filled nothing (`filled_fields` empty on all jobs). This run gives no evidence that it raises accuracy.
- The same test was not run on v26.1.16.51, so there is no before-and-after figure.
- Prompts and scoring differ from the 46/100 and about 66/100 scorecard, so these numbers cannot be compared with it.
