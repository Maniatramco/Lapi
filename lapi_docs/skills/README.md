# Skills

Claude Code skills that record how Lapi was built, so the same work can be repeated in Aegis or another app.

- `enterprise-app-hardening/`: HTTPS, Keycloak (roles, company sign-in), OpenFGA, route policy, sessions,
  roles and model Defaults, Access map, the narrated product tour (phone and computer versions), Quick start,
  and the chat design. Start with `SKILL.md`; details are in `reference/`.

To use it in Claude Code, copy the folder to `%USERPROFILE%\.claude\skills\` (personal) or to `.claude/skills/`
in the target repository. Keep this copy and the installed copy in step when either changes.
